HOSTELHUB - HOW TO RUN (Windows)

>>> DOUBLE-CLICK:  start.bat   (or RUN.bat)

Wait until you see:
  [BE] MongoDB connected successfully
  [BE] Server running on port 5000
  [FE] Local: http://localhost:5173/

Browser opens automatically to http://localhost:5173

REQUIREMENTS:
  - Node.js installed (https://nodejs.org/)
  - Internet (for MongoDB Atlas)
  - backend\.env must have your real MONGODB_URI from MongoDB Atlas

DO NOT:
  - Open index.html directly (white / broken page)
  - Close the terminal while using the app
  - Use http://localhost:5000 as the website (that is API only)

TROUBLESHOOTING:
  "Connection failed" = terminal closed or backend not started
  "Database not connected" = fix MONGODB_URI in backend\.env
  Port in use = close other HostelHub windows and run start.bat again
